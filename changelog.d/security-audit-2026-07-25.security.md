- **`/readyz` no longer returns the database exception text to unauthenticated callers.** It answers a fixed `"reason": "database_unavailable"` and logs the exception broker-side instead. `/readyz` is exempt from _both_ the bearer token and the tailnet source-IP ACL, so its body is readable by anyone who can reach the port; on the default SQLite backend the old message leaked little, but `JOBD_DB_URL` accepts any SQLAlchemy URL and a network driver puts host, port and username into it. The endpoint stays deliberately uncached — a cached readiness probe reports "ready" for the length of its TTL after the database has gone, which is wrong at the only moment the probe matters.
- **The tailnet source-IP ACL can no longer be influenced by a forwarded header.** uvicorn is now started with `proxy_headers=False`. Its default (on) lets a request from a trusted peer rewrite `request.client.host` out of `X-Forwarded-For` — the exact value the ACL decides on. This was inert in the shipped deployment (uvicorn only trusts the header from a `127.0.0.1` peer, and the broker binds directly to a tailscale IP under `network_mode: host`), and would have stopped being inert the moment a TLS-terminating reverse proxy was put on localhost in front of it.
- **A non-ASCII bearer token now returns 401 instead of 500.** `hmac.compare_digest` raises `TypeError` on a `str` holding non-ASCII, so the caller's own bytes decided the error shape; tokens are now compared as bytes. No token material was ever exposed.
- **A bearer token with surrounding whitespace now authenticates.** The expected value was already `.strip()`ed — `.env` files and systemd `Environment=` lines routinely carry a trailing newline — while the presented value was not, so a client echoing the operator's own trailing byte was rejected.
- **`docs/security.md` now documents the unauthenticated surface it previously denied.** The page claimed every request needs a bearer token; three endpoints (`/livez`, `/readyz`, `/metrics`) are exempt from both walls, and `/metrics` publishes the broker version, job counts, and every worker's hostname and version. A new `tests/test_security_doc_parity.py` derives that list from the live constants in both directions, so the page cannot drift again — it also caught a reference to `jobd_job_get`, an MCP tool removed on 2026-07-12.
