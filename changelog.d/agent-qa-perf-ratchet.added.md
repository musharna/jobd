- **Benchmarks: an agent A/B and a work-count perf ratchet.** `benchmarks/agent_qa/` asks Claude 41 read-only questions about a live broker (exit codes, hosts, run times, a project's failures on a day, log lines, routing) with no tools, with the `job` CLI, and with jobd-mcp. The key is drawn from the broker's HTTP API without importing `jobd`. Every setup reaches the broker through a loopback proxy that refuses anything but reads and dry-run submits, and the CLI setup's `job` refuses mutating subcommands. `benchmarks/perf/` counts the work per broker endpoint, scheduling pass and MCP tool on a fixed in-process fleet: jobd function calls, matcher calls, SQL statements and broker HTTP requests. `tests/test_perf_ratchet.py` fails on any difference from `baseline.json`, in either direction. The counts are identical on Python 3.11 to 3.14.
