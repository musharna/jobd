README's Security section said the broker had "two stacked controls" and stopped there, without disclosing that `/livez`, `/readyz` and `/metrics` answer with neither a bearer token nor a source-IP check — and that `/metrics` publishes every worker's hostname and version. `docs/security.md` already documented this; the README, which is what most readers judge the security posture by, did not. The parity test that was supposed to prevent exactly this drift only covered `docs/security.md`, so it now covers both.
