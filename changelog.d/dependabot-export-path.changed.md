- **The hashed Docker requirements export moved to `docker/requirements-docker.txt`.** It is a generated `uv export` of `uv.lock`, but at the repo root Dependabot's pip ecosystem (`directory: "/"`) discovered it as a _manifest_ and opened PRs editing it in place — which desyncs it from the source it is generated from, so every such PR failed the lockstep lint by construction, and merging one would have shipped dependency versions CI never ran (`uv.lock`, what the test job installs from, was left untouched). Dependabot has no per-file exclude, so relocating it out of the scanned directory is the supported fix. A new deploy-lint pins the placement in both directions: the export must not be at the root, and no dependabot pip entry may scan the directory it moved to. Regenerate with `uv export --frozen --no-dev --no-emit-project --format requirements-txt -o docker/requirements-docker.txt`.
